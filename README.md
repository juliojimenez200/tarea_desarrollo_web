# Portafolio web personal

Portafolio personal de Julio Jimenez desarrollado con HTML5, CSS3 y JavaScript puro. El sitio presenta informacion profesional, habilidades tecnicas, proyectos destacados, un Design System integrado y un formulario de contacto validado.

## Secciones

- Inicio
- Sobre mi
- Habilidades
- Proyectos destacados
- Design System
- Contacto

## Tecnologias

- HTML5 semantico
- CSS3
- CSS Custom Properties
- Flexbox
- CSS Grid
- Vanilla JavaScript
- Font Awesome para iconos

## Funcionalidades JavaScript

- Menu responsive
- Cambio de tema claro/oscuro con `localStorage`
- Filtro de proyectos por tecnologia
- Modal con detalle de proyectos
- Validacion del formulario de contacto
- Boton para volver al inicio

## Imagenes

Coloque sus imagenes dentro de la carpeta `assets/` con estos nombres:

- `avatar.jpg`: foto o avatar principal.
- `proyecto-nexo.jpg`: imagen de la card Nexo Finanzas.
- `proyecto-aula.jpg`: imagen de la card Aula Abierta.
- `proyecto-verde.jpg`: imagen de la card Verde Cerca.

Si alguna imagen no existe todavia, el sitio mantiene el diseno original de respaldo.

## Como verlo

Abra `index.html` directamente en el navegador o publique la carpeta en GitHub Pages.

## Publicacion sugerida en GitHub Pages

1. Crear un repositorio publico en GitHub.
2. Subir los archivos del proyecto.
3. Ir a `Settings > Pages`.
4. Seleccionar la rama principal y la carpeta raiz.
5. Probar la URL publicada en una ventana privada.
